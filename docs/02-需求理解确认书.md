## 1. 一句话理解

> 做一个 **Win10/64 与 Win11 通用的单文件绿色 exe**（中文、小体积、启动快、界面朴素），
> 用 **civitai 官方 REST API** 按 **模型/LoRA、作者、榜单、标签、关键词** 等条件**叠加过滤**，
> 批量抓取 **SFW+NSFW** 图片的 **正向/负向提示词 + Checkpoint/LoRA + 生成工具 + tags + 原始 JSON**，
> 结果**默认存本地 SQLite**（可回读、断点续传、去重），再按需导出 **CSV / JSONL / TXT**；
> 单任务默认上限 **1000 条**、约 **1 请求/秒**、遵守 civitai 条款，仅个人学习研究使用。

## 4. MVP 功能规格（我按确认表推导，最终以你确认的 C 点为准）

### 4.1 采集入口与过滤（可叠加，条件之间为“且”）
- **按模型 / LoRA**：输入模型 URL 或 ID，或站内搜索选模型；限定该模型/版本生成的图
- **按作者**：作者用户名或主页链接
- **按榜单**：排序（最新/最旧/最热/最多评论/最多收藏/随机）+ 周期（天/周/月/年/全部）
- **按标签**：多标签“全包含”（技术风险见 C4）
- **关键词**：见 C4
- **URL 列表**：粘贴单图/单帖链接批量解析（你未勾，但成本低，保留）
- **附加过滤**：
  - 生成工具：包含/排除（如排除 ComfyUI）——抓后按 meta 特征本地判断
  - 日期范围：起止日期
  - 内容分级：全部 / 只要 SFW / 只要 NSFW
- **数量**：目标保留条数，默认 1000，可改；超出即停并提示“已到上限”

### 4.2 字段（数据库 / 预览 / 导出）
`imageId`、`pageUrl`、`prompt`、`negativePrompt`、`lora`、`checkpoint`（模型名）、`modelId`、`modelVersionId`、`tool`（WebUI/ComfyUI/SD.Next/Krea/其他）、`tags`、`nsfwLevel`、`rawJson`（原始 JSON 整包）。

### 4.3 存储、去重、续传
- 本地 SQLite：`tasks`（任务与进度/cursor）、`items`（结果）、`settings`
- 去重：imageId 唯一；prompt 文本相同只留一条；空 prompt 跳过
- 断点续传：按任务保存 cursor 与已抓 ID，中断后续跑不重复
- 历史任务可回读、可再次导出

### 4.4 界面（任务台）
左侧配置（站点/内容级别、入口类型、条件、数量、日期、工具过滤、字段勾选）→ 开始；右侧任务队列、实时进度/速度、日志；下方结果预览表（可搜索/排序/勾选列，默认 6 列）；导出对话框（选列、选格式、选路径）；设置页（API Key、限速、超时、重试、代理、默认目录）；历史任务；最小化到托盘继续跑。

### 4.5 错误与合规
- 报错：人话原因 + “详情”展开技术信息（状态码/URL/响应片段）
- 合规：关于页声明；未成年内容硬编码拦截；只采公开内容；保留来源链接
- 交付物：exe + 《使用说明》+ 《误报处理说明》+ 验收清单

## 5. 技术方案与取舍

| 项 | 方案 |
| --- | --- |
| 语言/界面 | Python 3.12 + Tkinter/ttk（原生控件、朴素、小体积） |
| 网络 | 标准库 urllib（不引第三方 HTTP 库，减小体积/误报） |
| 存储 | 标准库 sqlite3 |
| 打包 | PyInstaller `--onefile`，不加密/不加壳，写版本信息与图标 |
| 兼容 | Win10 64 / Win11（同一 exe） |
| 体积/启动 | 预计 20–30MB / 1–2 秒（比 PySide6 小 3 倍） |
| 已实测可用 | `civitai.red` API 本机可直连（`/api/v1/images?withMeta=true` 正常返回，含 X 级；`.com` 本机不通，但 API 同源、你机器可通） |

> 说明：你选了“体积小、启动快”，所以我不再使用 PySide6。若你更看重界面精致，可回退 PySide6（60–90MB）。
