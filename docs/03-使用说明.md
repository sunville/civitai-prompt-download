# Civitai 提示词批量下载器 · 使用说明

版本 0.1.0 ｜ 适用：Windows 10 / Windows 11（64 位）

---

## 1. 这是什么

一个本地小工具：按条件批量抓取 civitai 上**公开可见**图片的**正向提示词、负向提示词、LoRA、Checkpoint、生成工具、Tags** 等数据，存到本地数据库，再导出成 CSV / JSONL / TXT / Excel。

- 数据来源：civitai 官方 REST API（`/api/v1/images?withMeta=true`）
- 不下载图片文件，只保存提示词与元数据
- 结果默认保存在本地 SQLite，可随时回读、断点续传、去重

---

## 2. 首次使用（3 步）

### 第 1 步：打开程序
双击 `CivitaiPromptDL.exe`。首次打开会创建数据目录（在 `%APPDATA%\CivitaiPromptDL`），不需要安装。

### 第 2 步：填写 API Key（强烈建议，非必需）
1. 点右上角「设置」→「API Key」右侧的「如何获取？」；
2. 在 civitai 网站登录后打开账号设置，创建一个 API Key；
3. 把 Key 粘贴到设置里并保存。

> 不填也能用（匿名），但更容易被限流；查询单张成熟内容图片时可能查不到。

### 第 3 步：选条件 → 开始
1. 左侧选择「采集方式」（按模型 / 作者 / 榜单 / 关键词 / 链接列表 / 站内搜索）；
2. 设置「过滤条件」（内容级别、排序、数量上限等）；
3. 点「加入队列并开始」；
4. 任务完成后，下方「结果预览」查看，点「导出」保存成文件。

## 3. 采集方式说明

| 采集方式 | 怎么用 | 说明 |
| --- | --- | --- |
| 按模型 / Checkpoint | 点「搜索 / 选择…」，输入关键词搜索，或粘贴模型链接/ID | 抓该模型下的示例图 |
| 按 LoRA | 同上，类型选 LoRA | 抓使用该 LoRA 的图 |
| 按作者 | 填作者用户名（也可粘贴作者主页链接） | 抓该作者的作品 |
| 按榜单 | 选排序 + 周期，不需要其他条件 | 抓全站最新/最热等 |
| 关键词（搜模型） | 输入关键词 → 搜索模型 → 选择模型 | **官方 API 不支持关键词搜图片**，所以先搜模型再抓图 |
| 图片 / 页面链接列表 | 每行一个链接：图片页 / 模型页 / 帖子 / 作者主页 | 适合手动整理的目标 |
| 站内搜索图片（实验） | 输入关键词 | 依赖**非官方**搜索服务，可能失效，且逐条补全很慢 |

### 关于「按标签」
- 本软件的「Tags」是**从提示词里拆出来的 tag**（逗号分隔，已去掉权重括号与 LoRA 语法），可在「过滤条件 → Tags」里要求**全部包含**；
- civitai 站内的分类标签（taxonomy tag）在图片接口里不返回，官方也没有公开的图片标签查询接口，所以第一版不做站内标签筛选。

## 4. 过滤条件

| 条件 | 说明 |
| --- | --- |
| 内容级别 | 全部 / 只要 SFW / 只要 NSFW；对应接口的浏览级别参数 |
| 排序 | 最新 / 最旧 / 最热 / 最多评论 / 最多收藏 |
| 周期 | 最近一天/周/月/年/全部（对「最新/最旧」不生效） |
| 日期范围 | 格式 `YYYY-MM-DD`；**只在「最新 / 最旧」排序下精确生效**，其他排序只能用周期近似 |
| 数量上限 | 筛选后**保留**的目标条数（默认 1000，可改） |
| 生成工具 | WebUI / ComfyUI / 站内生成器 / SD.Next / 其他 / 无参数；可多选，用来排除某类工具生成的图 |
| Tags | 逗号分隔，提示词必须**全部包含**这些 tag 才保留 |
| 解析模型名称 | 开启后会多请求几次接口把 Checkpoint / LoRA 的 ID 换成名字（有缓存） |

> 生成工具是按图片 meta 的特征判断的：ComfyUI 图片带 `comfy/workflow`；站内生成器带 `engine/ecosystem`；WebUI 带 `Model/sampler/steps`。判断不了的归为「其他」或「无参数」。

## 5. 任务队列

- **加入队列并开始**：新建任务并立即执行；如果已有任务在跑，会排队，完成后自动开始下一个。
- **暂停 / 继续**：暂停后当前请求结束即停；点「开始 / 继续」恢复（从断点继续，不会重抓）。
- **停止**：取消任务；已抓到的数据保留。
- **重试失败**：对失败/取消的任务继续跑（断点续传）。
- **删除**：删除任务及其结果（不可恢复）。
- **查看结果**：把下方预览切换到该任务。

任务状态：等待中 / 运行中 / 已暂停 / 已完成 / 失败 / 已取消。

---

## 6. 结果与导出

预览表格默认 6 列：正向提示词、负向提示词、LoRA、Checkpoint、生成工具、Tags；点「列设置」可以改。

双击某行可以看完整内容（含原始 JSON），并可一键复制正向/负向提示词。

点「导出」：
- 范围：当前任务 / 全部结果；
- 格式：
  - **CSV**（UTF-8 带 BOM，Excel 直接打开不乱码）
  - **JSON Lines**（程序再处理）
  - **TXT**（**只导出正向提示词**，无表头、每行一条，可直接粘进 WebUI）
  - **Excel .xlsx**
- 可选字段（默认已勾选常用字段）；
- 可按 NSFW 分级拆分文件。

默认输出目录：程序所在目录的 `output`（可在设置里改）。

---

## 7. 断点续传与去重

- 每个任务记录 cursor 与已抓条数，中断后继续时从断点接着抓；
- 图片按 `imageId` 全库去重（同一个图不会重复存）；
- 同一任务内，提示词文本完全相同的只保留一条；
- 没有提示词的图直接跳过（日志会统计数量）。

## 8. 常见问题

**Q：一直失败 / 提示网络错误？**
检查网络与代理。程序默认跟随系统代理（Clash 等 TUN 模式可直接用）；也可以在「设置 → 代理模式」里手动填 HTTP/SOCKS5 代理地址。

**Q：日志出现「HTTP 429 / 请求太频繁」？**
civitai 在限流。程序会自动退避重试；把「设置 → 请求间隔」调到 1.5–2 秒，或降低单任务数量。

**Q：数据里负向提示词是空的？**
正常。部分作者/工具没有上传负向提示词，接口里就没有。

**Q：导出的 CSV 用 Excel 打开乱码？**
请确认用的是本程序导出的 CSV（带 UTF-8 BOM）；如果被其他工具另存过，可能丢 BOM。

**Q：某些图片抓不到 / 跳过？**
- 作者没有公开提示词（meta 为空）→ 按规则跳过；
- 成熟内容且没填 API Key → 单张查询会失败，建议填 Key 或改用列表式抓取。

**Q：站内搜索（实验）报「服务不可用」？**
这是非官方接口，随时可能失效；请改用「按模型 / 作者 / 榜单」。

**Q：关闭窗口后程序不见了？**
默认最小化到系统托盘（可在设置里关闭）。双击托盘图标恢复，右键托盘可退出。

**Q：数据存在哪？**
- 配置与数据库：`%APPDATA%\CivitaiPromptDL`（`config.json`、`data.db`、`logs\app.log`）
- 导出文件：默认在程序目录的 `output`，也可在导出时另选。

**Q：卸载？**
直接删除 exe 和 `%APPDATA%\CivitaiPromptDL` 即可，不写注册表。
