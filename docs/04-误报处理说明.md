# 杀毒软件误报处理说明

本程序是使用 Python + Tkinter 开发、用 PyInstaller 打包的**单文件绿色工具**，没有安装行为、不写注册表、不加载驱动、不联网上传数据（只访问 civitai.com / civitai.red 的官方 API，以及可选的站内搜索服务）。

但打包类程序（尤其是 PyInstaller 单文件）**偶尔会被 Windows Defender 或其他杀毒软件误报**，常见提示是 `Trojan:Win32/Wacatac`、`Wacapew`、`ML.Attribute.HighConfidence` 之类。这通常是因为：

1. 单文件 exe 运行时会把自己解压到临时目录再执行 —— 这是 PyInstaller 的正常机制，和某些恶意程序的行为相似；
2. 程序体积较大、包含 Python 运行时；
3. 新文件没有数字签名、下载量少，信誉分低。

## 你可以这样确认它是安全的

1. **看来源**：文件由开发者本人打包交付，文件名 `CivitaiPromptDL.exe`；
2. **看行为**：程序只访问 `civitai.com` / `civitai.red` / `search-new.civitai.com`（实验功能）和本地文件；不会开机自启、不会写系统目录；
3. **看数据**：配置与数据库都在 `%APPDATA%\CivitaiPromptDL`，卸载直接删目录即可。

## 添加信任（按杀毒软件）

### Windows Defender
1. 打开「Windows 安全中心」→「病毒和威胁防护」；
2. 点「管理设置」→ 拉到底「排除项」→「添加或删除排除项」；
3. 添加「文件」，选择 `CivitaiPromptDL.exe`（或程序所在文件夹）；
4. 重新双击运行。

如果文件已被隔离：在「保护历史记录」里找到该条目 →「还原」。

### 360 安全卫士 / 360 杀毒
- 弹出拦截窗口时选择「允许程序运行」/「添加信任」；
- 或在「木马查杀」→「信任区」里添加程序所在文件夹。

### 火绒
- 弹窗选择「允许」；
- 或在「防护中心 → 信任区」添加程序路径。

### 其他
- 大部分杀软在详情/隔离区里都有「恢复并加入白名单」选项。

## 更稳妥的做法

- 首次运行前，先把程序放到一个固定目录（如 `D:\Tools\CivitaiPromptDL\`），再把这个目录加入排除项；
- 不放心的话，可以在虚拟机或 Windows 沙盒里先运行一次（程序不依赖网络也能打开界面，只是抓取会失败）；
- 每次更新 exe 后重新确认一次（文件哈希变化可能再次触发误报）。

## 给开发者的说明

- 打包时未使用 UPX 加壳/压缩（`upx=False`），减少误报；
- 如需进一步降低误报，可考虑：代码签名证书、固定发布路径、提交 Defender 误报申诉。
